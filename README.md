# Catálogo de precios

Página de la tienda: precios, ventas, inventario y reporte. Se instala como app en el celular.

- Los datos viven en tu hoja de Google (pestañas Productos, Ventas, etc.).
- `config.js` guarda la dirección de tu Apps Script (la que termina en `/exec`).
- Para cambiar de Apps Script, solo cambia esa dirección en `config.js`.
